# 商脉品牌

## 标识文件

| 文件 | 用途 |
|---|---|
| `shangmai-icon.svg` | 独立符号，适用于小尺寸图标 |
| `shangmai-logo.svg` | 浅色界面的商脉组合标识 |
| `shangmai-logo-dark.svg` | 深色界面的商脉组合标识 |

应用内的符号和浏览器图标由 `lib/branding/desenho.ts` 提供几何路径，
分别由 `components/branding/MarcaDoProduto.tsx` 和 `app/icon.tsx` 渲染。
保留运行时白标能力：安装或组织设置了自有名称、标识时，使用其配置；
没有自有配置时显示“商脉”。

## 视觉方向

- 浅暖灰背景、墨色正文、低饱和黄铜色作为品牌强调色
- 标识使用已选第一款图标的实体 S 形轮廓与三个连接节点；不使用细线替代图形
- 标识颜色随明暗主题变化；组合标识不附加“CRM”后缀

## 展示位置

登录、注册、密码恢复与 MFA 共用公开页面标识；桌面与移动侧栏共用侧栏标识；管理后台与入门引导使用独立符号；浏览器页签、Apple 主屏幕图标与 PWA 指向 `/icon`。独立演示页和本目录分享卡使用同一套轮廓。
