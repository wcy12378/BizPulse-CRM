# 本地演示指南

状态：2026-10-26 已通过本地开发与预编译演示的具名路线验收。详细结果见[交付审计](delivery-audit.md)。

## 启动

已有项目依赖、迁移完成的本地 Supabase 核心服务及本地环境配置后，在项目根目录运行：

```powershell
pnpm demo
```

该命令检查本地环境、幂等补充隔离 B2B 种子、按源码指纹检查构建，再启动预编译服务。首次构建较慢；相同源码和实际 BUILD_ID 匹配时复用构建。Windows 新缓存默认位于 `D:/CRM-local`；可通过 `CRM_RUNTIME_DIR` 指定其他本地数据目录。端口默认 3000，已被占用时查找 3001–3005，以终端显示的链接为准。检查配置而不启动：`pnpm demo -- --check`。

开发方式：`pnpm dev`。开发模式仍会按需编译，正式录屏/现场反复展示建议使用完成构建的 `pnpm demo`。不要同时启动重复构建。此命令并不自动安装 Docker 或创建缺失的 Supabase 基础设施。

开发模式首次或缓存逐出后的页面仍可能等待十余秒编译；不会把这种等待算成预编译演示的速度。预编译版本的本地验收侧栏导航为 220–988 ms，首次构建时间单独计算。当前演示入口为 `http://localhost:3000/demo/enter?next=/app`，只读离线实验室为 `http://localhost:3000/demo/offline`。

## 三条展示路线

1. **90 秒业务与人工控制**：打开 `/demo/offline?locale=zh-CN` → 运行本地多专家检查 → 对照新旧报价/交期证据 → 核验并保留新版 → 提议更新 → 人工批准 → 查看赢率从 62 到 84、等级 A → 撤销更新。所有数据与结果明确标为虚构演示，不产生实际外部操作。
2. **60 秒可靠性**：展开故障演练 → 在待审批时模拟并发版本变化 → 批准被安全拒绝 → 重置 → 模拟检查失败并重试；已加载页面断开外网后继续演示完整流程。存档损坏或浏览器禁止存储仍可操作。
3. **60 秒真实 CRM 与双语**：从 `/demo/enter` 进入隔离演示组织 → 浏览 B2B 漏斗、联系人与任务 → 切换中文/English → 查看默认阶段和金额币种。`/demo/enter` 会切换到专用演示账户；返回自己的工作区需重新登录。正常账号入口 `/login`，密码只保存在本地私密文件。

## 展示约束

只使用中英模式；客户自定义名称、产品型号、公司名不进行机器改写。无 Key 时从提示进入明确演示入口，不能将演示输出冒充真实模型调用。离线实验室没有数据库写入；隔离 CRM 种子有真实数据库数据。不要将二者混为同一种证明。

本地服务默认仅绑定回环地址。这里没有公网部署，也没有提交 GitHub。源码、README、SVG 与审计文档应先由项目所有者审阅，再进入发布步骤。
